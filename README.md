# Investment Quest

Public deployment assets for an independent investment learning companion. This repository intentionally contains only browser-delivered static assets. No personal progress or private source-development files are included.

## Run
Serve this folder with any static HTTP server. GitHub Pages serves main at the repository root. No build or account sign-in is required.

## Privacy and progress
Progress remains in each browser’s local storage. Moving to a different website address does not copy that storage automatically. In the old app, open My progress and Export progress; in this app use My progress and Import backup. Keep the original backup. This app contains no analytics or server-side progress sync.

## Coverage
50 original lessons, 150 original practice questions, 170 glossary terms, 119 public Capital Group product entries and 12 account groups. Sources, dates, limitations and learning-science explanations are shown inside the app. This is not the official CFA course, an exam pass predictor, or investment advice. Product data is a dated snapshot, not a live price or exhaustive global offering list. Historical results do not guarantee future returns.
